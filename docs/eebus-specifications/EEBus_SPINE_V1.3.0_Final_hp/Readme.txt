[EEBus SPINE V1.3.0] - FINAL
2023-8-31

This is the final release of the SPINE V1.3.0 specification.

It is devided into three folders:

In the folder "Documentation" you will find the following PDF documents:
- EEBus_SPINE_TR_Introduction.pdf
- EEBus_SPINE_TS_ProtocolSpecification.pdf
- EEBus_SPINE_TS_ResourceSpecification.pdf


In the folder "ExampleXMLs" you will find some examples of SPINE messages (referenced in EEBus_SPINE_TS_ProtocolSpecification.pdf).

In the folder "XSDs" you will find all SPINE XSDs that define the SPINE data model.
